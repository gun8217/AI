"실시간 병 이미지 결함 탐지를 위한 딥러닝 기반 접근법"


[프로젝트 설명]

YOLO – 병 이미지 내 결함 탐지 및 ROI 추출
 : 병 이미지에서 결함이 있을 법한 영역(ROI)을 빠르게 탐지
 (특징)
  - 객체 탐지 기반으로 결함 위치를 박스로 표시
  - 실시간 처리에 적합한 경량 모델
  - 다양한 결함 유형에 대해 빠르고 넓은 탐색 가능
  - 이미지 전체가 아닌 의심 영역 중심 분석에 유리
 
전이 학습 모델 1. CNN – 결함 유형 분류의 기본 모델
 : YOLO가 탐지한 영역을 기반으로 결함의 종류를 분류
 (특징)
  - 구조가 단순하고 해석이 직관적
  - 소규모 데이터셋에도 안정적인 성능
  - 전이 학습 없이도 빠른 프로토타입 구축 가능
  - 복잡한 결함보다는 명확한 패턴 분류에 적합

전이 학습 모델 2. EfficientNet – 고성능 결함 분류를 위한 전이 학습 모델
 : CNN보다 정교한 분류를 위해 사용되는 고성능 모델
 (특징)
  - 이미지 크기, 깊이, 너비를 균형 있게 확장
  - 전이 학습을 통해 적은 데이터로도 높은 정확도 확보
  - 다양한 결함 유형에 대해 정밀한 분류 가능
  - 연산 효율성과 정확도 모두 우수
