"뉴스 분류 파이프라인 구축"


[프로젝트 설명]

데이터 수집 및 전처리
 - 뉴스 기사 또는 텍스트 데이터를 수집
 - 불필요한 HTML, 특수문자 제거
 - 소문자 변환, 토큰화, 불용어(stop words) 제거

모델링 이후 후처리 작업으로 성능 높이는 작업 진행

정지 단어(stop words) 전략 수립
 - 정치, 웰빙, 감성 표현 등 오예측 유발 단어 선별
 - 카테고리별 오예측 샘플 분석을 통해 제거할 단어 결정
 - 제거 단어 리스트를 실험적으로 조정하며 성능 비교

텍스트 벡터화
 - TfidfVectorizer로 텍스트를 수치화
 - ngram_range, max_features, stop_words 등 하이퍼파라미터 조정

모델 학습
 - LogisticRegression 선택
 - 학습 데이터로 모델 훈련
 - 교차 검증 또는 테스트셋으로 성능 평가

성능 평가 및 튜닝
 - 정확도, precision, recall, f1-score 확인
 - 오예측 샘플 분석 → stop_words 수정 → 재학습 반복
 - 최적 성능 도달 (정확도 91.23%)

실제 기사 예측
 - 새 기사 입력 → 벡터화 → 모델 예측
 - 예측된 카테고리와 확률 출력
 - 예측 결과 해석 및 문맥 기반 분석
