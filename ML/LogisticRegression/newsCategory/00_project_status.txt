"뉴스 분류 파이프라인 구축"


[프로젝트 설명]

1. 데이터 수집 및 전처리
 - 다양한 뉴스 기사 또는 텍스트 데이터 수집
 - HTML 태그, 특수문자 등 불필요한 요소 제거
 - 전체 소문자 변환, 토큰화(tokenization) 수행
 - 불용어(stop words) 제거로 의미 없는 단어 필터링

2. 정지 단어(stop words) 전략 수립
 - 정치, 웰빙, 감성 표현 등 오예측을 유발하는 단어 선별
 - 카테고리별 오예측 샘플을 분석하여 제거할 단어 결정
 - 제거 단어 리스트를 실험적으로 조정하며 성능 비교

3. 텍스트 벡터화
 - TfidfVectorizer를 활용해 텍스트 데이터를 수치화
 - ngram_range, max_features, stop_words 등 하이퍼파라미터 조정
 - 다양한 설정을 실험하여 최적의 벡터화 방식 도출

4. 모델 학습
 - 분류 모델로 Logistic Regression 선택
 - 전처리된 데이터를 기반으로 모델 학습 수행
 - 교차 검증 또는 테스트셋을 활용해 초기 성능 평가

5. 성능 평가 및 튜닝
 - 정확도(Accuracy), 정밀도(Precision), 재현율(Recall), F1-score 등 주요 지표 확인
 - 오예측 샘플 분석 → stop_words 수정 → 재학습 반복
 - 반복 실험을 통해 최적 성능 도달 (최종 정확도 91.23%)

6. 실제 기사 예측
 - 새 뉴스 기사 입력 시, 동일한 전처리 및 벡터화 적용
 - 학습된 모델을 통해 카테고리 예측 수행
 - 예측된 카테고리 및 확률 출력
 - 예측 결과에 대한 해석 및 문맥 기반 분석 진행
