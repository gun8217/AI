"대출 승인 여부 예측"


[프로젝트 설명]

1. 데이터 전처리
 - 고객의 소득(income), 신용 점수(credit_score), 포인트(points) 등 수치형 변수 수집
 - 이상치 제거 및 결측치 처리
 - StandardScaler를 사용해 수치형 변수 표준화 (z-score 변환)
 - points 변수는 구간화하여 points_bin (Low, Medium, High) 범주형 변수로 변환

2. 모델링
 - 분류 모델로 DecisionTreeClassifier 선택
 - 표준화된 데이터를 기반으로 모델 학습
 - 모델이 자동으로 선택한 분기 기준(z-score 기준)을 바탕으로 규칙 생성
   예: income <= -0.75, credit_score <= 0.03 등

3. 모델 해석 및 규칙 추출
 - 학습된 트리 모델에서 주요 분기 기준 추출
 - z-score 기준을 실제 값으로 역변환하여 해석 가능하게 변환

4. 규칙 기반 예측 함수 구현
 - 모델의 주요 분기 기준을 사람이 이해할 수 있는 형태로 재구성
 - 복잡한 모델 없이도 빠르고 직관적인 예측 가능

5. 가상 예측 시나리오 시연

6. 활용 및 확장
 - 실제 서비스에 적용 시, points_bin 자동 계산 로직 추가 필요
 - 모델 객체 저장(pickle) 또는 규칙 기반 함수 저장(.py)로 배포 가능
 - 향후 모델 성능 향상을 위해 다른 알고리즘(Logistic Regression, XGBoost 등)과 비교 가능
