🔵 Cluster 1
특징: 데이터 포인트가 많이 몰려 있음.
[해석]
 - 이 그룹은 전형적인 고객층일 가능성 높음.
 - 소비 패턴이나 행동이 평균적이며, 극단적인 특성이 없음.
 - 마케팅 타겟으로 삼기 좋은 안정적인 고객군
 
🟠 Cluster 0
특징: Cluster 1과 비슷한 위치에 있지만 약간 다른 방향으로 분포. 역시 데이터가 많이 몰려 있음.
[해석]
 - Cluster 1과 유사하지만 약간 다른 행동 특성을 가진 고객군.
 - 구매 빈도는 비슷하지만 평균 구매 금액이 다를 수 있음.

🟢 Cluster 2
특징: 데이터 포인트가 적고 넓게 퍼져 있음. 다른 클러스터와 명확히 떨어진 위치.
[해석]
 - 특이한 행동을 보이는 고객군으로 해석 가능
 - 고가 제품을 선호하거나, 구매 빈도가 매우 낮거나 높을 수 있음
 - VIP 고객 또는 비정기적 대량 구매자일 가능성

🔴 Cluster 3
특징: Cluster 0과 공간적으로 인접. 중심점은 비슷하지만 분산이나 밀도에서 차이 가능.
[해석]
 - 유사한 소비 패턴을 보이지만, 특정 변수에서 차별화됨.
 - 구매 빈도는 비슷하지만 평균 구매 금액이 더 높거나 낮음.
 - 특정 제품군에 대한 선호도가 더 뚜렷함.
 - 고객 충성도나 이탈 가능성이 다름.
