"인도 교통사고 데이터 기반 위험군 탐지 및 대응 전략"


[프로젝트 설명]

t-SNE – 사고 패턴의 시각적 구조 파악
 - 고차원 교통사고 데이터를 2차원으로 축소하여 시각적으로 분포를 파악
 - 비선형 관계나 복잡한 사고 유형 간의 유사성을 시각적으로 표현
 - 클러스터 간 경계나 중첩을 직관적으로 확인 가능

KMeans – 사고 유형별 군집화 및 정책 타겟팅
 - t-SNE로 축소된 데이터를 기반으로 군집 중심(Centroid) 기준으로 사고 유형을 분류
 - 각 클러스터는 운전자 행동, 사고 조건, 지역 특성 등을 반영한 그룹으로 해석 가능
 - 클러스터별로 위반 유형, 평균 속도, 음주 수치 등을 분석해 맞춤형 대응 전략 수립

Heatmap – 클러스터별 사고 유형의 빈도 시각화
 - 각 클러스터에서 발생한 교통 위반 유형의 빈도를 색상으로 표현
 - 색이 진할수록 해당 위반이 자주 발생한 것으로, 단속 우선순위나 교육 캠페인 타겟팅에 활용 가능
 - 지역별·시간대별로 위반 유형을 교차 분석하여 위험군 집중 구역 도출

클러스터별 맞춤 대응
 - Cluster 1: 야간 집중 단속, 면허 확인 강화, 음주 캠페인
 - Cluster 3: 도심 주차 단속 강화, 운전 중 휴대폰 사용 경고
 - Cluster 4: 과속 카메라 설치, 헬멧 착용 캠페인
